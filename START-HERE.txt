WHAT YOU CAN DELETE / REPLACE
-----------------------------

1. SAMPLE PROVIDERS
   You may DELETE the entire:
   assets/MEGA888/
   assets/JILI/

   Then create your real provider folders.

2. SAMPLE GAME IMAGES
   great-blue.png
   lucky-panda.png
   ocean-king.png
   fortune-gems.png

   These are only example placeholders. Delete/replace them.

3. PROVIDER LOGO
   Put the provider logo directly inside provider folder:
   assets/MEGA888/provider-logo.png

   Keep the exact file name:
   provider-logo.png

4. GAME CATEGORY
   Folder name becomes category:
   assets/MEGA888/Slots/
   assets/MEGA888/Fishing/
   assets/MEGA888/Arcade/

5. GAME IMAGE
   Put image inside category:
   assets/MEGA888/Slots/great-blue.png

   The website changes "great-blue.png" into:
   Great Blue

6. OPTIONAL TIPS / NOTES
   Use SAME file name as the image:

   great-blue.png
   great-blue.txt

   If .txt exists, website shows:
   "View Tips / Notes"

   If you don't need tips, just don't create the .txt file.

GITHUB PAGES SETUP
------------------

After uploading all files:

GitHub repository
-> Settings
-> Pages
-> Build and deployment
-> Source: Deploy from a branch
-> Branch: main
-> Folder: / (root)
-> Save

Your website should then be:

https://YOUR-USERNAME.github.io/game-asset-hub/


IMPORTANT
---------

The repository must be PUBLIC because the website reads the public GitHub
file tree to auto-detect new providers and game images.

After the first setup:
YOU DO NOT NEED TO EDIT index.html.

Just add/delete folders and images inside assets/.
