# Game Asset Hub — Clean Sample

Start with **START-HERE.txt**.

### Main rule

```text
assets/PROVIDER/CATEGORY/game-name.png
```

Example:

```text
assets/MEGA888/Slots/great-blue.png
```

Optional tips:

```text
assets/MEGA888/Slots/great-blue.txt
```

Provider logo:

```text
assets/MEGA888/provider-logo.png
```

After setup, you normally only edit the `assets/` folder.
